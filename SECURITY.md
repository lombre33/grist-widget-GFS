# Signaler une vulnérabilité

Une faille dans GFS, dans son courtier ou dans la façon dont il isole les apps se signale **sans ouvrir d'issue publique** : tant
qu'elle n'est pas corrigée, une issue la rendrait publique.

- **Sur GitHub** : onglet « Security » du dépôt, puis « Report a vulnerability » (signalement privé).
- **Politique de divulgation de l'État** (pour une faille touchant une instance Grist officielle) :
  <https://vdp.numerique.gouv.fr/p/Send-a-report>

Dites ce que vous avez observé, comment le reproduire (document, app, navigateur) et ce que la faille permet. Une réponse vient
avant toute publication ; la correction se publie avec la mention de qui l'a signalée, si vous le souhaitez.

Une faille dans une app (Publipostage+, Form+, Automation+, Grist-BI) ou dans le kit se signale dans le dépôt de cette app ou du
kit ; une faille dans une bibliothèque tierce, auprès de son auteur.
