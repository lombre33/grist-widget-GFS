Essai à trois pages : LanguageTool dans le cadre d'une app

Une seule question : LanguageTool travaille-t-il dans le cadre d'une app posé comme GFS le pose dans Grist (la page de Grist, GFS dedans, l'app dedans : trois pages l'une dans l'autre) ? Cinq cadres : le premier est le réglage d'aujourd'hui, les suivants changent le nom du site de l'app, écrit avec un point à la fin (lombre33.github.io., ce que le navigateur prend pour une autre adresse), ou la façon dont le cadre est isolé. La page ne touche à aucun document Grist.

Cette page est déjà à l'adresse avec le point : l'essai ne vaudrait rien. Ouvre-la par l'adresse du site, sans le point à la fin du nom.

  1. Ouvre la page par son adresse, dans Firefox avec LanguageTool activé (sans l'enregistrer). Dans chaque cadre, clique dans les deux zones de texte (elles contiennent des fautes), attends deux secondes, puis réponds à « LanguageTool corrige ici ? » : oui s'il souligne ou propose une correction, non si seul Firefox souligne.
  2. Le rapport tout en bas se remplit seul. Copie-le avec le bouton et colle-le dans la conversation.
